# ADR 0005: Создание StateManager в подсистеме памяти

## Статус
Принято (Accepted)

## Контекст
Агенту DonMir Boot Agent необходим легкий механизм сбережения оперативного состояния и контекста сессий на диске для восстановления работы после пересборки или перезапуска.

## Решение
1. Реализован модуль `memory/state_manager.py` с классом `StateManager` (персистентное хранилище JSON).
2. Написаны автотесты `tests/test_state_manager.py`.

## Последствия
- Агент получает возможность персистентного сохранения состояния.
- Готова база для создания Истории Сессий и Кэша контекста (Шаг 2 Этапа 3).
