# ADR 0002: Выделение SystemCore и ConfigManager в ядре платформы

## Статус
Принято (Accepted)

## Контекст
В рамках Этапа 2 («Ядро платформы») необходимо перейти от прототипа в `main.py` к модульной архитектуре ядра согласно принципу «Сначала платформа — потом продукты».

## Решение
1. Создан модуль `core/config_manager.py` с классом `ConfigManager` для загрузки и доступа к конфигурации JSON.
2. Создан модуль `core/system.py` с классом `SystemCore` для управления жизненным циклом агента и сбора метрик системы.
3. Точка входа `main.py` обновлена и выступает в роли оркестратора.
4. Добавлены автотесты в `tests/test_core.py` для контроля компонентов ядра.

## Последствия
- Повышена модульность и тестируемость кода.
- Платформа готова к подключению Шины Событий (Event Bus) на Шаге 2.
