# ADR 0003: Реализация базовой шины событий (Event Bus)

## Статус
Принято (Accepted)

## Контекст
Для обеспечения принципа слабой связанности (Decoupling) компонентов платформы требовался механизм обмена событиями в реальном времени.

## Решение
1. Реализован модуль `core/event_bus.py` с классом `EventBus` (паттерн Publish/Subscribe).
2. Интегрирован `EventBus` в `SystemCore` для оповещения подписчиков о событиях `system_started` и `system_shutdown`.
3. Написаны изолированные автотесты `tests/test_event_bus.py`.

## Последствия
- Подсистемы агента (плагины, память, интерфейсы) смогут реагировать на события системы без прямых вызовов.
