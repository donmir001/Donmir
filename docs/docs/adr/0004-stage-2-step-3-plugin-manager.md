# ADR 0004: Создание PluginManager (Менеджера плагинов)

## Статус
Принято (Accepted)

## Контекст
Платформе DonMir Boot Agent необходим механизм динамического обнаружения и подключения расширений (плагинов/продуктов) без изменения основного кода ядра.

## Решение
1. Реализован модуль `core/plugin_manager.py` с классом `PluginManager` для поиска (`discover_plugins`) и динамического импорта (`load_plugin`) модулей.
2. Создан первый демо-плагин `plugins/sample_plugin.py`.
3. Добавлены автотесты в `tests/test_plugin_manager.py`.

## Последствия
- Платформа готова к динамическому расширению функционала через сторонние и встроенные плагины.
- Завершён базовый функционал **Этапа 2: Ядро платформы (Platform Core)**.
