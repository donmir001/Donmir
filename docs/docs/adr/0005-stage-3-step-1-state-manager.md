# ADR 0005: Создание StateManager в подсистеме памяти

## Статус
Принято (Accepted)

## Контекст
Агенту DonMir Boot Agent необходим легкий механизм сбережения оперативного состояния и контекста на диске для восстановления работы после перезапуска.

## Решение
1. Реализован модуль `memory/state_manager.py` с классом `StateManager` (персистентное хранилище JSON).
2. Добавлены автотесты в `tests/test_state_manager.py`.

## Последствия
- Подсистема памяти (Этап 3) получила возможность персистентного сохранения состояния.
