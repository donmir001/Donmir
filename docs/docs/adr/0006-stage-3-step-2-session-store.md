# ADR 0006: Создание SessionStore для хранения историй сессий

## Статус
Принято (Accepted)

## Контекст
Для сохранения диалогового контекста и хронологии агенту необходимо локальное хранилище историй конкретных сессий.

## Решение
1. Реализован модуль `memory/session_store.py` с классом `SessionStore`.
2. Добавлены автотесты `tests/test_session_store.py`.

## Последствия
- **Этап 3: Подсистема памяти и состояния (State & Memory Engine)** официально завершён.
