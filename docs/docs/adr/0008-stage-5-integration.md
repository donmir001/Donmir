# ADR 0008: Полная интеграция и оркестрация платформы DonMir Boot Agent

## Статус
Принято (Accepted)

## Контекст
Все подсистемы платформы (ConfigManager, SystemCore, EventBus, PluginManager, StateManager, SessionStore, TaskRunner) созданы. Требовалось объединить их в единый оркестрируемый цикл в `main.py`.

## Решение
1. Обновлен `main.py` для сквозной инициализации и управления всеми подсистемами.
2. Создан интеграционный автотест `tests/test_integration.py`.

## Последствия
- Полностью завершена разработка Платформы согласно ROADMAP v1.0 («Сначала платформа — потом продукты»).
